class CAE(nn.Module):
    def __init__(self):
        super(CAE, self).__init__()
        self.encoder = nn.Sequential(
            nn.Conv2d(in_channels=1, out_channels=16, kernel_size=3, stride=2, padding=1),
            nn.ReLU(),
            nn.Conv2d(in_channels=16, out_channels=32, kernel_size=3, stride=2, padding=1),
            nn.ReLU(),
            nn.Flatten(),
            nn.Linear(32 * 7 * 7, 20)
        )
        self.decoder = nn.Sequential(
            nn.Linear(20, 32*7*7),
            nn.Unflatten(1, (32, 7, 7)),
            nn.ConvTranspose2d(in_channels=32, out_channels=16, kernel_size=3, stride=2, padding=1, output_padding=1),
            nn.ReLU(),
            nn.ConvTranspose2d(in_channels=16, out_channels=1, kernel_size=3, stride = 2, padding = 1, output_padding = 1),
            nn.Sigmoid()
            )

    def forward(self, x):
        encoded = self.encoder(x)
        decoded = self.decoder(encoded)
        return decoded

# Noise function  
def add_noise(images, noise_factor):
    noisy = images + noise_factor * torch.randn_like(images)
    return torch.clamp(noisy, 0.0, 1.0)

The convolutional autoencoder was better than PCA for preserving spatial structure, as demonstrated by the visual reconstruction of 5 sample digits above. This is because the convolutional layers of the convolutional autoencoder look at small areas of pixels at a time, so the details of the image stay sharp, but PCA reconstructions look blurry because the model treats images as one long list of numbers, so it doesn't know which pixels are next to each other. This quality/accuracy, however, comes with a tradeoff, as the convolutional autoencoder took roughly 415 seconds to train and 1.6 seconds to infer, while PCA took 0.3 seconds to train and 0.029 seconds to infer. This is one of the key differences between autoencoders and PCA, as PCA is very fast, but autoencoders require training, making the computation slower. The autoencoder also achieved a lower test MSE (0.01595) than PCA (0.03407).
